# 결정 사전 템플릿

결정 사전은 기획자와 합의한 **여러 기능에 공통으로 쓰는 기본값** 목록이다. `figma-to-qa-cases` 는 미정의 항목을 찾으면 먼저 사전을 보고, 해당 항목이 있으면 질문하지 않고 그 값을 쓴다.

규칙

- 기획자가 답한 결정 중 다른 기능에도 적용되는 것만 넣는다. 한 화면에만 해당하는 답은 그 기능의 `draft.json` 에만 남긴다.
- 추가와 변경은 사용자 확인 후에 한다. 근거(누가, 언제, 어느 기획서 질문)를 반드시 적는다. 이유: 근거 없는 기본값은 나중에 틀려도 아무도 고치지 못한다.

예시 행 (복사하지 않는다)

| ID   | 유형      | 상황            | 기본값                                     | 근거                                        |
| ---- | --------- | --------------- | ------------------------------------------ | ------------------------------------------- |
| D-01 | 상태 누락 | 목록 API 가 0건 | 빈 화면 일러스트 + "아직 ○○이 없어요" 문구 | 기획 담당, 2026-11-20, water-log U-03 답변 |

## 복사할 부분

아래 줄부터 끝까지를 설정의 `decisions` 경로에 그대로 복사한다.

```markdown
# 기획 결정 사전

기획자와 합의한 공통 기본값. 추가는 근거(합의자, 날짜, 출처 질문)와 함께 한다.

| ID | 유형 | 상황 | 기본값 | 근거 |
| -- | ---- | ---- | ------ | ---- |
```
